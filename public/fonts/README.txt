Archivo and Bebas Neue are the latin subsets from Google Fonts.

Spark Scope Mono is a subset of D2Coding 1.4.0 (github.com/naver/d2-coding-font, release VER1.4.0), used by the
TUI Panel and TUI Classic designs. "D2Coding" is a Reserved Font Name, so the subset carries its own name; the
copyright and licence entries of the original name table are kept. It holds printable ASCII, Latin-1, general
punctuation, the 2,350 Hangul syllables of KS X 1001 and every other character in public/*.js, *.css and *.html
that D2Coding has. Made with fontTools (pip install fonttools brotli): subset each TTF with flavor woff2 and all
layout features, then set name IDs 1-4 and 6 to "Spark Scope Mono" (Regular or Bold, PostScript SparkScopeMono-*).

The copyright lines match the fonts' own name tables. The fonts keep their own license regardless
of the license chosen for the rest of Spark Scope.
